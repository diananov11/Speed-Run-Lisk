# 🚀 Speed Run Lisk — Build a Simple NFT Marketplace

This project is part of the **Lisk SEA Campaign Week 5 Challenge**, focused on build a fully functional NFT marketplace where users can list, buy, and sell NFTs with real-time USD price display powered by oracles.

---

## 📖 Project Overview

This project demonstrates how to start the frontend local and you can see list of NFTs and make a transaction like sell.

## 🧑‍💻 How to Run Locally

### 1️⃣ Clone the repository

```
git clone https://github.com/diananov11/Speed-Run-Lisk.git
git switch week-5
cd Speed-Run-Lisk
```

### 2️⃣ Install dependencies

```
yarn install
```

### 3️⃣ Start the frontend in local

```
yarn start
```

Try to see, buy and sell NFTs
